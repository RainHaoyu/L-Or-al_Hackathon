# 万象 Aura · 工程包使用说明

> 2026 欧莱雅美妆科技黑客松 · 赛道三「无界体验家」
> 双核心：**致敏预警（QRA2 四闸门）+ 香味可视化（组成驱动显影）**
> 本包开包即用：双击 `一键启动.bat`（Windows）/ `一键启动.command`（macOS）。

---

## 一、最快上手（Windows）

1. **唯一前提**：安装 [Node.js LTS](https://nodejs.org/zh-cn)（一路下一步即可）。
   - 后端为**可选项**：有 Python 3.10+ 体验更完整（引擎信封/真实识别通道），没有也完全能跑——前端自动回退本地引擎。
2. 解压本包，**双击 `一键启动.bat`**：
   - 首次运行自动安装依赖（约 2-5 分钟；如慢可先执行 `npm config set registry https://registry.npmmirror.com` 换国内镜像）；
   - 检测到 Python 会顺带在 8001 端口起后端（独立窗口，可随时关闭）；
   - 完成后自动打开浏览器 **http://localhost:5199**。
3. 关闭对应命令行窗口即停止服务。

**无 Node 的极简演示模式**（直接看界面）：有 Python 的前提下双击 `启动后端.bat`，或手动执行
`python -m http.server -d aura\web\dist 8080` 后访问 http://localhost:8080（预构建版本；直接刷新子页签可能 404，从首页进入即可）。

## 二、包内结构

```
万象Aura-工程包/
├── 一键启动.bat / 启动前端.bat / 启动后端.bat / 数据重生成.bat   # Windows 双击脚本
├── 一键启动.command / .sh                                        # macOS / Linux
├── aura/
│   ├── web/        前端（React19+Vite7+Tailwindv4；dist/ 为预构建产物）
│   │   ├── src/lib/qra2/      QRA2 引擎（LHS 蒙特卡洛，与后端逐位对齐）
│   │   ├── src/lib/vision/    可视化映射引擎（情绪板/降级隔离）
│   │   ├── src/data/          共享数据层（管线产物，前后端同源）
│   │   └── scripts/build_data.py  数据层 → JSON 管线（纯标准库）
│   └── api/        后端（FastAPI，可选）
│       ├── app/modules/        qra2 移植 / 识别层(四通道) / LLM 编排(三级兜底)
│       └── tests/              pytest 13 条
├── 数据层/         8 份原始数据（12款香水/IFRA 51st/CAS词典/EU26/IgE/香材词典/HEX色值）
├── 技术可行性与开发路线图.md
└── IMPROVEMENT_PLAN.md         全部迭代与验收记录（12 节）
```

## 三、常用操作

| 目的 | Windows | 命令行等价 |
|---|---|---|
| 启动前端 | 双击 `启动前端.bat` | `cd aura\web && npm run dev` |
| 启动后端（可选） | 双击 `启动后端.bat` | `cd aura\api && .venv\Scripts\uvicorn app.main:app --port 8001` |
| 改了数据层原始文件 | 双击 `数据重生成.bat` | `cd aura\web && python scripts/build_data.py` |
| 跑前端测试（35 条） | — | `cd aura\web && npm test` |
| 跑后端测试（13 条） | — | `cd aura\api && .venv\Scripts\pytest -q` |
| 前端类型再生成（改了后端契约后） | — | `cd aura\api && .venv\Scripts\python scripts\gen_api_types.py` |

## 四、接入真实大模型（可选）

默认全链路离线可跑（识别走 mock、文案走模板）。配置阿里百炼 Key 后自动切换真实模型：

1. [百炼控制台](https://bailian.console.aliyun.com/) 创建 API-KEY；
2. 启动后端前设置环境变量（PowerShell：`setx DASHSCOPE_API_KEY "sk-xxx"` 后重开窗口；或改 `启动后端.bat` 在首行加 `set DASHSCOPE_API_KEY=sk-xxx`）；
3. 重启后端：拍照识别走 `qwen-vl-max`，通感文案走 `qwen-max`（报告页引擎徽章可见实际模型）。

## 五、演示脚本（90 秒）

1. 首页「或直接打开一份演示结果」→ **孕期 × 香奈儿五号**（黄灯：麝香临床提示 + IFRA 限值）；
2. 返回 → **敏感肌 × 迪奥清新之水（开封 14 个月）**（红灯：萜烯氧化 × 敏感肌 P99 分位）；
3. 「查看香气显影」→ 顶栏切**失嗅模式**（加长叙事 + 语音播报）→ 切**敏感模式**（风险条前置）；
4. 手动通道粘贴 `Eugenol: 0.6%, Limonene: 15%, 安息香` 看四级真实判定（超限红 / 触限红 / IgE 速发）。

## 六、常见问题

- **端口占用**：5199/8001 被占时改 `启动前端.bat` 里的 `--port`（后端端口改动需同步 `aura/web/src/lib/api.ts` 的 `VITE_API_BASE` 或建 `.env.local` 写 `VITE_API_BASE=http://localhost:新端口/api/v1`）。
- **杀毒软件拦截 bat**：右键「以管理员身份运行」或允许通过。
- **npm 安装失败**：切换镜像（见上文）或删除 `aura\web\node_modules` 后重试。
- **后端起不来**：不影响前端，页面右下角引擎徽章会显示「本地引擎」，全部功能仍可演示。
- **Windows SmartScreen 提示**：bat 为普通脚本，点「仍要运行」。
