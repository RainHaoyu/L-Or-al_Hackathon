## 一、最小用法（Windows，只需要 Python）

```bat
cd web && npm install && npm run build      rem 构建同源页面（交付包已带预构建 web/dist，可跳过）
```

然后仓库根目录双击 **`启动后端.bat`**（或 `python -m uvicorn app.main:app --host 0.0.0.0 --port 8001`），
浏览器打开 **http://localhost:8001** —— **同一个进程**同时提供页面与接口，没有跨域问题。

- **开发模式**（需要 Node）：`启动前端.bat`（vite 热更新，3000）+ `启动后端.bat`（8001）
- **数据管线**：`数据重生成.bat`（`数据层/` → `web/src/data/*.json`，幂等可重跑）
- **打交付包**：`python scripts/make_release.py` → 产出 `万象Aura-交付包-<日期>.zip`

## 二、手机访问（同一 Wi-Fi）

服务监听 `0.0.0.0`，手机打开 `http://<电脑内网IP>:8001`（启动脚本会把两个地址都打印出来）。
打不开时基本都是 **Windows 防火墙**拦了入站 8001，用管理员身份执行一次：

```
netsh advfirewall firewall add rule name="WanxiangAura-8001" dir=in action=allow protocol=TCP localport=8001
```

多网卡机器（有线 + 无线 + 热点/虚拟网卡）上，脚本打印的可能是第一个 IPv4；
必要时用 `ipconfig` 找「无线局域网适配器 WLAN」那一节的地址。

## 三、AI 文案与拍照识别（可选，不配也能完整跑）

三级兜底：qwen-max → qwen-plus → 规则模板；识别：qwen-vl-max → mock。
不配 Key 时功能完整、不报错，页面会**如实标注**文案来源（"后端 AI" 还是 "本地规则模板"）。

配 Key 两种方式：

- 临时：`set DASHSCOPE_API_KEY=你的Key` 后再启动；
- 持久：复制 `api/.env.example` 为 `api/.env` 并填入 Key（后端用 dotenv 读取）。
  `.env` 已在 `.gitignore` 里 —— **绝不入库、绝不打进交付包**（`make_release.py` 有硬校验）。
