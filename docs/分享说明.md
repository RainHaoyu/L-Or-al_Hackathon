## 二、启动指南

**前端**（先启动，不依赖后端也能完整演示）：

```bash
cd web
npm install
npm run dev           # http://localhost:5173（演示用 --port 5199）
npm run test          # vitest 27 条（QRA2 18 + 可视化 9）
npm run build
```

**后端**（可选；不启动则前端自动回退本地引擎，报告页徽章显示「本地引擎」）：

```bash
cd api
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8001     # 前端默认连 http://localhost:8001/api/v1
.venv/bin/python -m pytest tests/ -q           # 11 条
```

**接入阿里百炼（可选）**：bailian.console.aliyun.com 创建 API-KEY 后：

```bash
export DASHSCOPE_API_KEY=sk-xxx   # 再启动 uvicorn
# 图像识别自动切 qwen-vl-max（否则 mock），通感文案自动切 qwen-max（否则模板）
# 冒烟：curl -X POST localhost:8001/api/v1/recognition/image -H 'Content-Type: application/json' \
#        -d '{"image":"<base64>","filename":"t.jpg"}'   → meta.provider == "qwen-vl-max" 即生效
```

**重新生成数据 / 前端类型**（改了数据层原始文件或后端契约时）：

```bash
python3 web/scripts/build_data.py                      # 数据层 xlsx/docx → web/src/data/*.json
cd api && .venv/bin/python scripts/gen_api_types.py    # openapi → web/src/lib/api-types.ts
```

> 注意：`web/scripts/build_data.py` 读取仓库根 `数据层/` 目录（本包未含 xlsx/docx 原始文件，队友本地已有）。
> macOS 上请勿在项目目录内跑 `npm install` 覆盖软链 node_modules（本包无此问题，全新安装无碍）。

## 五、关键设计口径（答辩要点）

- 风险方向：`safety_ratio = AEL / CEL`，越大越安全；红线 = P99 余量 < 1（全人群一致），
  黄线 = 人群判定线 AEL/CEL[policy]/T_pop < 1（健康 P90，脆弱人群 P99 × T_pop）
- 数据诚实：文献 NESIL 标 documented、demo 估计 ÷3 惩罚标 indicative、无数据显式黄灯「数据不足 ≠ 安全」
- 身份画像 ↔ 顶栏模式双向联动（敏感⇄敏感肌、失嗅⇄失嗅人群；普通档不丢孕期/鼻炎画像）
- 可复算：LHS 固定种子，任何人重算逐位一致（meta.seed 上报）
