## 项目简介

万象Aura 是一个面向香水消费场景的 AI 辅助决策系统，核心能力是 **香味可视化 + 致敏原智能预警**。

项目源于“无界体验家”赛道命题：用 AI 帮助更多群体平等地享受美、体验美。我们聚焦一个长期被忽视的问题：失嗅人群、敏感肌人群、孕妇等群体，如何安全地、有尊严地体验香水之美？

当前香水消费市场存在两个核心痛点：

- **信息壁垒**：香水成分表对普通消费者而言是“天书”。26 种 IFRA 列明的致敏香料、复杂的香调金字塔、晦涩的 INCI 名称，即使非失嗅人群也难以判断一款香水是否适合自己。
- **感官缺失**：失嗅人群无法通过嗅觉感知香水的层次变化，也无法感知香水变质后产生的刺激性气味。当柠檬烯、芳樟醇等成分氧化生成强致敏氢过氧化物时，正常人可能通过“off-note”感知变质，而失嗅者完全依赖视觉预警。

万象Aura 希望通过“实体交互 + 人工智能”的新模式，将具身智能、多感官交互、智能感知等前沿技术方向引入香水体验场景，让技术真正服务于人。

## 核心功能

### 1. 致敏原智能预警

目标：将 IFRA/RIFM 的 QRA2 定量毒理学框架，工程化为可复算、可审计、可解释的风险评估引擎，让敏感人群获得“因人而异”的安全指引。

#### 1.1 概率化 QRA 量化风险评估模型

QRA（Quantitative Risk Assessment，定量风险评估）是 IFRA/RIFM 采纳的、基于暴露量的皮肤致敏定量风险评估方法。核心计算框架：

- AEL = NESIL ÷ SAF（可接受暴露水平）
- 风险判定：AEL / CEL ≥ 1 → 可接受；AEL / CEL < 1 → 不可接受

参数说明：

- NESIL：无预期致敏诱导水平（基准剂量），来源为局部淋巴结试验（LLNA）的 EC3 值，或人体 HRIPT/HRPT 数据。
- SAF：致敏评估因子（安全系数），由种间差异（×10）、个体差异（×10）、产品/使用场景考虑（×1-10）组成，范围 10-1000。
- AEL：可接受暴露水平，计算得出 = NESIL ÷ SAF。
- CEL：消费者暴露水平，基于产品类型、单次用量、涂抹面积、使用频率计算。

CEL 计算示例（驻留型香水）：

CEL = 成分浓度(%) × 单次产品用量 × 涂抹面积(cm²) × 日使用频率 × 皮肤吸收率

例如，某香水中含柠檬烯 5%（0.05），单次喷洒 0.5mg/cm² 于 100cm² 手腕，日使用 2 次，皮肤吸收率保守假定为 100%：

CEL = 0.05 × 0.5 × 100 × 2 × 1.0 = 5.0 μg/cm²/day

若该成分的 NESIL 为 10,000μg/cm²，SAF = 100，则：

AEL = 10,000 ÷ 100 = 100 μg/cm²/day

风险比值 = AEL ÷ CEL = 100 ÷ 5.0 = 20.0 → 远大于 1，低风险

#### 1.2 从静态点估计到概率化暴露评估

传统 CEL 是一个静态点估计，隐含三个未经检验的假设，而这三个假设恰恰在最需要保护的脆弱人群身上失效：

- 所有消费者单次用量相同，实际用量呈右偏长尾分布，重喷者可达典型值 3-5 倍。
- 使用频率取“平均值”，补喷行为、季节差异、多部位叠加使用高度离散。
- 忽略个体皮肤屏障差异，敏感肌屏障受损者经皮吸收率显著上升。

本方案将 CEL 的输入参数由标量升级为概率分布，通过蒙特卡洛模拟输出 CEL 的完整概率分布，并提取 P50/P90/P99 分位值作为分级判据。

模拟流程（N = 10,000 次迭代）：

1. 参数化：依据产品类别（驻留型/冲洗型）加载对应分布族与超参。
2. 抽样：采用拉丁超立方抽样（LHS）替代简单随机抽样，在小样本下即可获得更稳定的尾部估计。
3. 逐次求解：对第 i 组抽样参数计算 CEL_i = c_i × m_i × A_i × f_i × η_i。
4. 分位提取：对 {CEL_i} 排序，输出 CEL_P50、CEL_P90、CEL_P99，并固定随机种子以保证结果可复算。

判定规则升级：以分位数替代单点。

- AEL/CEL_P50 ≥ 1：典型消费者安全，绿灯。
- AEL/CEL_P90 ≥ 1：90% 消费者安全，绿灯（附用量建议）。
- AEL/CEL_P90 < 1：约 10% 消费者暴露超标，黄灯，推送“减半用量/隔日使用”干预。
- AEL/CEL_P99 < 1：存在极端暴露尾部风险，红灯，建议敏感肌、孕妇避免使用。

保守化原则：对健康成人以 P90 为判定基准；对敏感肌、孕妇、失嗅人群自动提升至 P99，即“最脆弱的人，用最保守的分位线保护”。

#### 1.3 聚合暴露预留接口

香水从来不是孤立暴露源。同一香型的沐浴露、身体乳、洗发水、止汗露往往共享同一香精配方，构成对同一致敏原的多源叠加暴露。欧盟消费品科学委员会（SCCS）在其《化妆品成分测试与安全评估指南》中持续强调聚合暴露评估的重要性，这也是当前监管审查的明确趋势。

本方案在架构层面预留该能力：

- 香型谱系字段：数据库 product 表预留 scent_lineage 字段，标记同香型产品族。
- 共暴露权重 w：依据品类共使用场景设定（如身体乳 w=0.8，洗发水 w=0.3，冲洗型折减），默认 1.0（单点模式）。
- 聚合暴露接口：calc_aggregate_exposure(cas, user_product_set)，Stub 已实现，返回单点 CEL；数据完备后开关切换。
- 输出兼容：聚合 CEL 直接接入蒙特卡洛管线，复用 P90/P99 判据。

#### 1.4 双轨校验：QRA 计算 + 临床激发阈值交叉验证

QRA 的局限性必须被诚实面对。欧盟消费品科学委员会（SCCP）在评审 QRA 方法时明确指出：“该方法尚未经验证，亦无验证策略方案。无法确信 QRA 所确定的皮肤致敏物暴露水平对消费者是安全的。”

SCCP 建议对已知致敏物的安全水平确定应基于临床数据和/或激发低效应水平。为此，本方案将单一判据升级为三闸门串联（Take-the-Most-Strict）架构：

- 闸门 1：QRA 概率化模型（AEL/CEL_P90 or P99），前瞻性定量预测，覆盖无临床数据的成分，但模型本身未经验证。
- 闸门 2：临床激发阈值（LOEL/NOEL）与人体斑贴试验数据，以真实人体数据兜底，但仅覆盖有临床数据的已知致敏原。
- 闸门 3：IFRA Standards 强制限量，合规硬约束，但是限量而非风险值。

最终风险等级 = 三个闸门输出中的最严等级。任一闸门缺失时（如无临床数据），系统不静默降级，而是在报告中显式标注 evidence_level: QRA_only，把不确定性诚实呈现给用户。

#### 1.5 关键定量风险分析发现

在量化风险评估（QRA）研究中，研究者测定了 107 款喷雾香水中 25 种过敏原的含量，发现即使在同一类别产品中，不同过敏原因致敏 potency 不同，安全阈值差异巨大。

女性香水数据示例：

- 柠檬醛（Citral）：AEL/CEL 比值 0.19，存在风险。
- 异丁香酚（Isoeugenol）：AEL/CEL 比值 0.13，存在风险。
- 新铃兰醛（HICC）：AEL/CEL 比值 0.67，存在风险。
- 百合醛（Lilial）：AEL/CEL 比值 0.53，存在风险。
- 2-辛炔酸甲酯（Methyl 2-octynoate）：AEL/CEL 比值 0.57，存在风险。

风险解读：当 AEL/CEL 比值低于 1 时，意味着在该产品的常规使用场景下，该成分对敏感人群存在不可接受的致敏风险，需要进行风险管理。

#### 1.6 氧化产物动态风险评估方法

柠檬烯和芳樟醇本身是前半抗原（prehapten）——低致敏或无致敏性，但接触空气后自氧化生成强致敏的氢过氧化物。这一特性使静态的成分标注无法反映真实风险。

临床阳性率：基于丹麦哥本哈根根措夫特医院 2014-2025 年对 6719 名患者的斑贴试验数据显示：

- 对氢过氧化芳樟醇（Lin-OOH）的阳性反应率为 3.1%。
- 对氢过氧化柠檬烯（Lim-OOH）的阳性反应率为 1.6%。
- 交叉反应性：研究证实，这两种氧化产物之间存在交叉反应性，且常与其他香料过敏原同时呈阳性。

氧化风险动态评估模型设计：

氧化程度 D = f(t, T, L, C₀, k_ox)

其中：

- t = 开封后时间（天）
- T = 储存温度（℃）
- L = 光照暴露程度（0-1）
- C₀ = 烯类成分初始浓度（%）
- k_ox = 氧化速率常数（柠檬烯 k ≈ 0.01-0.05/天，芳樟醇 k ≈ 0.005-0.03/天，受温度/光照加速）

风险等级：

- D < 0.2（开封 < 3 个月，阴凉避光）：低，正常使用。
- 0.2 ≤ D < 0.5（开封 3-12 个月）：中，建议敏感肌与孕妇减少使用。
- D ≥ 0.5（开封 > 12 个月或高温光照）：高，强烈建议不再使用。

对失嗅人群的特殊意义：正常人可能通过气味变化（氧化后的“off-note”）感知香水变质，但失嗅者无法依赖此通道。本模块为失嗅者提供了嗅觉替代预警。

#### 1.7 人群差异化风险分级算法

基于 QRA 基准风险比，通过人群安全阈值收缩实现差异化预警。客观风险比对所有人群一致，差异体现在各人群的安全阈值宽严：

- 客观风险比：R_base = CEL/AEL
- 人群安全阈值：T_pop = T_base × α(population)，T_base = 1.0
- 风险定级：
  - R_base ≥ T_pop × 1.0 → 高风险
  - R_base ≥ T_pop × 0.5 → 中风险
  - 否则 → 低风险

人群标签与参数：

- 健康成人：α = 1.0，无附加检查项。
- 敏感肌：α = 0.5（阈值降 50%），交叉反应检查（同族致敏原）。
- 孕妇：α = 1.0，生殖毒性成分检查（邻苯二甲酸酯、Lilial）。
- 过敏性鼻炎：α = 1.0，高挥发性醛类呼吸道刺激标注。
- 失嗅人群：α = 1.0，嗅觉替代预警（氧化 D 值强视觉推送）。

设计原则：α 仅反映生理耐受差异（敏感肌阈值更严）；β 仅反映实际暴露量变化（密闭空间、高频使用）；失嗅人群的感知缺失由交互层补偿，不参与风险计算，避免与氧化量化重复加权。

#### 1.8 高频最常见致敏香料

日常香水大量出现的核心致敏香料：

- Limonene 柠檬烯：柑橘精油来源，香柠檬/橙子/柑橘调；氧化后致敏性大幅上升，久放香水风险变高。
- Linalool 芳樟醇：薰衣草、佛手柑、橙花；氧化产物刺激性很强，最常见香料过敏原之一。
- Geraniol 香叶醇：玫瑰、天竺葵，甜花香；花香调香水几乎普遍含有。
- Citral 柠檬醛：强烈柠檬香气，柑橘、花香调；接触性皮炎高发。
- Eugenol 丁香酚：丁香油，辛香、东方调；刺激性较强，IFRA 严格限用量。
- Cinnamal 肉桂醛：肉桂香气，辛香调，强致敏物。
- Coumarin 香豆素：香草、干草甜香，美食调；兼具光敏性，晒太阳更容易泛红发痒。
- Citronellol 香茅醇：玫瑰花香原料，广泛用于花香香水。
- Isoeugenol 异丁香酚：温暖辛香，IFRA 极低上限，高致敏性。
- Hydroxycitronellal 羟基香茅醛：经典铃兰花香原料，花香调高频成分。
- Farnesol 法呢醇：茉莉、橙花，花香柑橘调；易氧化致敏。
- Benzyl salicylate 水杨酸苄酯：花香定香剂，很多白花调香水都有。
- Oak moss 树苔净油/橡苔：西普调经典原料，致敏极强，IFRA 大幅限制使用量。

#### 1.9 过敏反应分类

（1）挥发物刺激反应（非过敏）

香水喷洒后释放的苯、甲醛等物质，可能刺激眼鼻黏膜，诱发哮喘或过敏性鼻炎。症状：局部皮肤瘙痒/红斑、打喷嚏、流泪、呼吸困难（严重时可能引发过敏性休克）。多数属于挥发性物质对黏膜的非特异性刺激反应，不属于免疫介导过敏；仅少数个体发生 IgE 介导气道致敏时，才属于真正过敏。皮肤香料接触过敏（IV 型迟发型）主要表现在皮肤，一般不以呼吸道症状为主。

（2）过敏性接触皮炎 IV 型迟发型接触性皮炎（最典型的香水过敏）

香水中半抗原（芳樟醇、香叶醇、肉桂醛、橡苔等香料分子）结合皮肤蛋白，触发免疫反应。症状：接触部位红斑、瘙痒、丘疹、小水泡；脖子、手腕、耳后、眼睑高发。欧盟化妆品法规列出 26 种香料致敏原。

（3）IgE 介导速发型过敏（部分人群）

初次接触香料，机体产生特异性 IgE，结合在肥大细胞、嗜碱性粒细胞表面。多见于呼吸道吸入过敏、鼻炎哮喘。症状：几分钟发作，风团/荨麻疹/嘴唇肿。致敏原：天然提取物中残留的植物大分子蛋白。

### 2. 香味可视化系统

目标：让失嗅人群“看见”香味，让所有人“读懂”香味。

#### 2.1 香水可视化内容逻辑

核心逻辑：嗅觉 → 参数映射 → 视觉编码 → 视觉呈现。香水 → 文本解析 → 嗅觉特征编码 → 生成提示词 → AI 文生图 → 结果展示。

简易流程：

1. 拆解香水：提取前/中/后调原料、香型、浓度、风格情绪。
2. 给每个原料分配：颜色 + 形状图标。
3. 选择模式：静态金字塔 OR 动态粒子流体。
4. 映射：权重 → 色块宽度/粒子数量；时序 → 图层顺序/动画时间；强度 → 透明度大小。
5. AI 输出高级视觉画面。

模拟时间变化 = 香味随时间变化对应不同颜色；色块宽度 = 香气占比权重，越宽代表这个调占香水比重越高。

#### 2.2 跨模态映射理论基础

“气味 → 视觉”的映射并非主观臆造，而是有坚实的跨模态感知研究支撑：

- Gilbert、Martin 与 Kemp（1996）在《American Journal of Psychology》发表的开创性研究证明：对于 20 种测试气味，受试者能产生一致的、非随机的颜色联想，且 2 年后的重测相关性显示这种映射具有高度稳定性。
- 牛津大学 Charles Spence 教授（2020）在《Cognitive Research: Principles and Implications》发表的综述梳理了过去 25 年间至少 20 篇同行评审研究，确认了普通人群（非联觉者）中气味-颜色映射的稳健性，并提出四种解释框架：统计学习、语义中介、结构对应、情绪中介。
- Russell 等人（2015）对嗅觉-视觉联觉者的研究发现，气味的视觉化不仅涉及颜色，还包括形状与图案（如“巧克力闻起来是粉色且带条纹的”），这为本方案的“动态图形”维度提供了直接依据。

#### 2.3 气味 → 视觉的映射规则设计

基于上述理论，本方案设计了“香调类型 → 视觉三要素”的映射规则库：

- 花香调：粉/紫，花瓣飘落，温柔、浪漫。理论依据：统计学习（花朵 → 粉/紫）。
- 木质调：棕/墨绿，树干纹理，沉稳、温暖。理论依据：语义中介（木材 → 棕色）。
- 柑橘调：黄/橙，光线跃动，清新、活力。理论依据：统计学习（柑橘 → 黄/橙）。
- 东方调：深红/金，香料旋涡，浓郁、神秘。理论依据：情绪中介（浓郁 → 深色）。
- 馥奇调：翠绿/青，蕨类摇曳，自然、清新。理论依据：结构对应（清凉 → 冷色）。
- 美食调：暖棕/奶白，蒸汽升腾，甜蜜、舒适。理论依据：统计学习（食物 → 暖色）。
- 西普调：苔绿/琥珀，树影斑驳，优雅、深邃。理论依据：语义中介（草本 + 木质）。

#### 2.4 可视化呈现形式

系统输出“四维可视化”呈现：

- 色彩方案：主色 + 辅色 + 背景渐变，基于香调金字塔（前调/中调/后调）生成色彩层次。
- 动态图形：Lottie/Canvas 粒子动画，对应香调的视觉意象。
- 雷达图：ECharts 渲染，维度包括“清新度、甜度、浓郁度、温暖度、持久度”。
- 文字描述：LLM 生成通感化文字描述（如“仿佛走进雨后柑橘园，晨光透过枝叶”），辅助视觉理解。

#### 2.5 无障碍适配

- 失嗅模式：强化色彩对比 + 动态图形 + 雷达图；详细通感化描述（“雨后柑橘园晨光”）。适用人群：嗅觉障碍人群。
- 普通模式：视觉辅助 + 嗅觉引导；简要香调说明。适用人群：健康人群。
- 敏感模式：风险色标（红/黄/绿）突出；侧重风险与成分说明。适用人群：敏感肌/孕妇。

### 3. 瓶身 AI 识别与成分解析

#### 3.1 多模态识别技术路线

采用“双通道”识别策略以提高准确率与覆盖面：

- 通道 A：瓶身拍照。输入香水瓶身图像，技术方案为多模态大模型（通义千问 VL/GPT-4o）→ 香水 ID，输出品牌 + 品名 → 数据库精确匹配。
- 通道 B：条形码扫码。输入 GTIN/EAN，技术方案为条码识别 API → 香水 ID，输出精确匹配检索。
- 通道 C：文字输入。输入品名模糊搜索，技术方案为 Elasticsearch，输出候选列表。
- 补充通道：拍成分表。输入成分列表图像，技术方案为 PaddleOCR/云 OCR API → 成分文本，输出成分文本提取。

- 前端：Web / 小程序，支持输入、结果展示、模式切换。

- 可视化层：香调映射、雷达图、通感文字、粒子动画、AI 文生图。
