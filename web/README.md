# 万象 Aura · Web（aura/web）

> 2026 欧莱雅美妆科技黑客松 · 赛道三「无界体验家」
> 双核心 Demo 前端：**致敏预警（QRA2 迷你闸门）+ 香气显影（组成驱动可视化）**

## 快速开始

```bash
npm run dev            # 开发服务器（Vite，默认 5173；--port 5199 自定义）
npm run build          # 类型检查 + 产物构建（tsc -b && vite build）
npm run preview        # 预览构建产物
```

> 依赖通过本地盘缓存软链安装（`node_modules` 为符号链接）。
> 如依赖缺失，运行 web-replicate skill 的 `relink-node-modules.sh`；
> 在 macOS 上若报 `mv -T` 相关错误，属脚本 GNU 兼容问题，需手动落位 master 缓存（见改进清单第 7 节备注）。

## 页面与职责

| 路由 | 页面 | 职责 |
|---|---|---|
| `/` | 首页 | 介绍区（人群数据/痛点/定位）→ **三步引导流**：①身份画像五选一 ②四通道识别（搜索/拍照降级/条码/手动）③开封与储存情境（实时算氧化 D）→ 生成报告；演示案例入口 |
| `/report` | 预警报告 | 检验单式文档：判定横幅（红/黄/绿 + 逐条理由 + 行动建议）、四闸门读数、P50/P90/P99 分位条、氧化 D 仪表、成分明细（证据等级标签）、免责声明 |
| `/vision` | 香气显影 | 香调分层（层高=权重、色块=香材占比）、全瓶香型组成条、分层液体瓶图、**组成驱动的飘落粒子**（粒数∝层权重×香材占比、颜色=十二香型 HEX、形状随族）、五维雷达、通感文字 + 语音播报 |

三模式（普通/失嗅/敏感）在顶栏切换，作用于一组 CSS token 覆盖与字号放大，非三套页面。

## 数据与「诚实性」口径

- **真实数据层已接入（2026-10-05）**：`python3 scripts/build_data.py` 解析 `数据层/` 原始文件生成 `src/data/*.json`（幂等可重跑）：
  - `perfumes.json` — **12 款真实经典香水**（《12款经典香水分析.docx》：迪奥清新之水/香奈儿五号/蝴蝶夫人/一千零一夜/杜桑/香草烟草/鼠尾草与海盐/光影皮革/墨恋/红色百家乐540/无极乌龙/真我），含品牌、香调（映射到十二香型族）、浓度类型（EDP/EDT/EDC）、前中后调香材（逐香材推断香型族）、成分清单、品鉴关键词；另保留黄金算例教学样本
  - `ifra.json` — **IFRA 51st Amendment Cat4 三表**：限量 20 条（CAS/中英文名/上限%，如柠檬醛 0.6%、香豆素 1.6%、异丁香酚 0.05%）、完全禁用 9 条（铃兰醛、海葵醛、硝基麝香、薄荷内酯等，CAS 碎片已修复）、天然精油限制 2 条
  - `ingredients.json` — 160 条 CAS 词典（天然/合成/香精三源）
- **判定消费真实数据**：禁用闸门命中真实禁用清单；IFRA 闸门按 Cat4 限值真实判定（手动输入带浓度：≥限值红、≥80% 黄、低于绿）；五维雷达由族先验按组成加权生成；风险画像（萜烯/麝香/限值命中数）由真实成分清单推导
- 十二香型 HEX 色值与场景来自《香型HEX色值及对应画面效果.docx》
- 氧化模型 `D = 1 − exp(−k·t)`，k 标定：阴凉 0.0013 / 室温 0.0023 / 高温 0.0045 每天；3 个月阴凉避光 D≈0.12 判「低」
- 诚实口径：库内香水成分无逐项浓度 → 表头标「浓度（典型值）」、明细行标注「该香水未披露此成分浓度」；手动未命中项按「数据不足」黄灯，不静默（P0-4/P1-1 精神）

## 设计系统「墨与光」

- Tailwind CSS v4 token：`src/index.css`（瓷白底 + 墨字 + 金点缀；风险三色永远伴随图标与文字）
- 字体：Cormorant Garamond + 宋体（标题/大数字）、Manrope + 苹方（正文），@fontsource 自托管
- 签名元素：顶栏十二香型光谱带；首页柔光渐变背景（`.aurora-bg`）
- 无障碍：对比度 ≥4.5:1、触控 ≥44px、A+ 字号两档、Web Speech 中文播报、`prefers-reduced-motion` 降级、粒子画面带 sr-only 文字摘要
